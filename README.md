# Tr-e-V0r — application de trading assistée par IA

Plateforme de trading algorithmique pilotée par une architecture d'agents IA,
conçue comme un produit : GitHub → Cloudflare → iPhone.

> **État actuel : phase d'architecture.** L'audit des dépôts de référence et
> l'architecture cible sont rédigés ; l'implémentation de la V0.1 suit.

Logiciel expérimental. Aucune décision produite par ce système ne constitue un
conseil en investissement. Le trading comporte un risque de perte en capital.
